# 🌿 Ataramor (Атарамор)

**Ataramor** — це цифровий простір для медитації, де давня стратегія зустрічається зі спокоєм ранкового саду та таємницями густого мороку. Це подорож для тих, хто шукає мудрості в тиші та красу в кожному кроці.

---

## ✨ Концепція гри

### 🧘‍♂️ Сад Ранішнього Каменя
Весь інтерфейс гри створений як втілення естетики **Zen Garden**. Світлі тони, текстура старого пергаменту та м'яке сяйво золота налаштовують на вдумливу гру. Тут немає зайвого шуму — лише ви, дошка та ваші думки.

### 🌑 Майстерня Загадок та Карта Мороку
Світ Ataramor розділений на світло та тінь. У режимі навчання ви потрапляєте на **Карту Мороку**:

* **Розсіювання темряви:** Кожна розв'язана задача (цумего) стає іскрою світла. Проходячи рівні, ви буквально відвойовуєте територію у темряви, перетворюючи пустку на квітучий сад.
* **Золотий Ліхтар:** Магічний супутник, що допомагає підсвітити вірний шлях у найтемніші моменти вашої подорожі.

---

## 🌬️ Супутники (Твої опоненти)

Замість холодних алгоритмів, вашими суперниками стануть стихії та духи саду, кожен з яких має свій характер гри:

1.  **Шепіт Вітру** — легкий та невловимий, ідеальний для перших кроків.
2.  **Ранковий Туман** — загадковий та мінливий, що приховує свої справжні наміри.
3.  **Непохитна Скеля** — символ міцної оборони та фундаментальної стратегії.
4.  **Стихія** — непередбачувана потужність для справжніх майстрів.

---

## 📜 Душа гри

Ataramor натхненний глибиною української поезії та філософією Го. У грі ви знайдете:

* **Поетичні відлуння:** Проходження складних етапів відкриває рядки з творів **Василя Симоненка** та **Василя Стуса**, що резонують із вашим ігровим досвідом.
* **Сезонні зміни:** Світ гри змінюється разом із реальним часом. Зимова крига, весняний цвіт сакури чи осінній листопад — кожна пора приносить нові унікальні карти та виклики.
